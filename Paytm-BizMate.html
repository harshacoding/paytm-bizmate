Problem Statement

Merchants piece together short settlements by hand.

Merchant request · synthetic example

“Why did I receive ₹18,400 instead of ₹20,000?”

The bank credit alone cannot explain which refunds, charges or unsettled payments account for the difference.

Trace the settlement

Match payments and deductions across reports, then follow up on what is still missing.

Bring customers back

Find people who have stopped visiting, prepare an offer and check who received it.

Proposed Solution

Natural conversations. Guided workflows. Real outcomes.

Merchants can interact with BizMate using everyday language, just like talking to a colleague. BizMate understands their intent, guides them through the process, asks for approval before important actions, and confirms when the task is completed.

Product vision

One AI teammate for everyday merchant operations.

Settlement investigation

₹166.80 still needs an explanation.

Scheduled check

Open an investigation

A scheduled check flags the short payment. When the mock settlement report times out, BizMate uses transaction, refund and chargeback records to reconcile the amounts in paise.

Resume the next morning

With the merchant’s approval, BizMate opens a support ticket, verifies it and schedules a follow-up. The next morning it checks a fresh mock settlement record for the ₹166.80 credit before closing the case.

Technology / Tech Stack Used

How one agent plans, acts and verifies

Merchant interface

React + TypeScript

Accepts requests, shows evidence and collects approvals.

→

Backend

Python + FastAPI

Validates each request and enforces merchant permissions and approvals.

→

Agent orchestration

LangGraph + LLM

Discovers permitted tools in the registry, builds a structured plan and validates each step before execution.

Persistent execution

SQLite and LangGraph checkpoints save the case, approvals and next action. Each tool result can trigger a retry, a revised plan or an independent verification read.

Tools and mock services

Python functions reconcile paise and segment customers. Mock Paytm APIs, a synthetic CRM, campaign delivery and ticketing services supply records and receipts.
